# Dependencies (Spring Initializr)

| Kategorie       | Dependency             | Zweck                                              |
|-----------------|------------------------|----------------------------------------------------|
| Web             | Spring Web             | REST Controller, HTTP                              |
| Security        | Spring Security        | Auth, JWT, Roles                                   |
| Data            | Spring Data JPA        | MySQL-Datenbank                                    |
|                 | MySQL Driver           | JDBC-Treiber                                       |
|                 | Spring Data MongoDB    | Chat-Daten (NoSQL)                                 |
| Messaging       | WebSocket              | Realtime Chat                                      |
| Validation      | Validation             | Bean Validation (DTOs)                             |
| Developer Tools | Spring Boot DevTools   | Live Reload & Hot Restart                          |
| Testing         | Spring Boot Test       | Unit & Integration Tests                           |
| (Optional)      | Lombok                 | Kürzere Entities/DTOs (Getter/Setter via Annotation)|

## Setup & Installation

- Spring Boot Version: 3.5.7
- Java Version: 21
- Maven Version: 4.0.0
- MySQL Version: 8.0+
- MongoDB Version: 6.0+
- Node.js Version: 24.11.0 LTS
