# Konventionen und Standards

Code Style: Prettier + ESLint (Frontend & Node)

Branch Naming:

feat/<feature> – neue Features

fix/<issue> – Bugfixes

chore/<task> – Setup, CI/CD, Docs

Commit Messages: Conventional Commits
Beispiel: feat(auth): add JWT-based authentication

Pull Request Template: mit Beschreibung, Screenshot, Testhinweis

Issue Templates: für Bug & Feature Requests
